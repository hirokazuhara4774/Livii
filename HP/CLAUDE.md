# ホームページ（HP）

Livii のホームページです。ファイルを開けばそのまま表示できる静的なサイトです。

## ページ構成

| ページ | ファイル | 色 |
| --- | --- | --- |
| 総合トップ | `index.html` | 生成り×チャコール（2ブランドへの案内） |
| Livii（住まいを整える） | `reform/index.html` | オレンジ×ネイビー（ロゴと同じ） |
| Livii不動産（住まいをつなぐ） | `fudosan/index.html` | 白・深緑・チャコール |

- 共通の見た目は `assets/style.css`。ブランドの色は `body` のクラス（`t-group` / `t-reform` / `t-estate`）で切り替える。
- アイコンは各ページの先頭にある SVG（`<symbol id="i-…">`）を `<use href="#i-…">` で使う。新しいアイコンは3ページすべてに足す。
- 画像は `assets/img/`。仮写真（`assets/img/photos/`）は Unsplash License の写真で、公開前に実際の写真へ差し替える。

## 物件の追加（Livii不動産）

売買・賃貸の物件は `assets/data/properties.js` に書き足すと、`fudosan/index.html` の「売買物件情報」「賃貸物件情報」に自動で表示される。HTML は触らない。

### 手順

1. 物件の写真を `assets/img/properties/` に入れる。ファイル名は物件番号にする（例: `S-0002.jpg`）。横長（4:3 くらい）、幅 1200px 程度に縮小してから入れる。
2. `assets/data/properties.js` の `sale`（売買）か `rent`（賃貸）に、既存の物件をまねて `{ ... },` をひとつ追加する。
3. 物件番号 `id` は、売買は `S-0001` から、賃貸は `R-0001` から連番。
4. 状態 `status` を必ず入れる。
   - 売買: `"販売中"` / `"商談中"` / `"成約済"`
   - 賃貸: `"募集中"` / `"申込あり"` / `"成約済"`
   - `"成約済"` にすると一覧の最後に薄く表示され、問い合わせボタンが消える。掲載をやめるときはデータごと削除する。
5. 本物の物件を載せたら、`sample: true` の掲載例（`S-0001` / `R-0001`）は削除する。

### 項目

| 項目 | 売買 | 賃貸 | 例 |
| --- | --- | --- | --- |
| `type` 種別 | ○ | ○ | 中古戸建 / 土地 / マンション / 収益物件 / アパート |
| `title` 物件名 | ○ | ○ | 荒尾市 庭付き2階建て |
| `price` 価格 | ○ | | 1,980万円 |
| `rent` 賃料 / `fee` 管理費 | | ○ | 5.8万円 / 管理費 3,000円 |
| `deposit` 敷金・礼金 | | ○ | 敷金 1ヶ月／礼金 なし |
| `address` 所在地 | ○ | ○ | 番地まで出すかは売主・貸主と相談 |
| `access` 交通 | ○ | ○ | JR荒尾駅 車で5分 |
| `layout` 間取り | ○ | ○ | 4LDK |
| `land` 土地面積 / `building` 建物面積 | ○ | | 198.50㎡ |
| `area` 専有面積 | | ○ | 52.80㎡ |
| `built` 築年月 | ○ | ○ | 2008年3月 |
| `features` 特徴 | ○ | ○ | ["駐車場2台", "南向き"] |
| `image` 写真 | ○ | ○ | S-0002.jpg |

### 掲載前の確認

- 売主・貸主から、ホームページへの掲載の了承をもらっているか。
- 価格・賃料・面積・築年月が資料と合っているか。
- 取引態様（媒介など）を `note` に書いたか。不動産の広告は表示のルール（不動産の表示に関する公正競争規約）に沿って書く。
- 宅地建物取引業の免許番号がフッターに入っているか（免許取得前は物件を掲載しない）。

## 事業別 LP（広告・SNS 用）

広告・Instagram・チラシの QR から直接来てもらうための1ページです。メニューを置かず、その事業の相談（電話・LINE）に集中させる。

| 事業 | URL（HP からの相対パス） | ブランド |
| --- | --- | --- |
| 外構工事 | `lp/gaiko/` | Livii |
| リフォーム工事 | `lp/reform/` | Livii |
| 外壁塗装 | `lp/gaiheki/` | Livii |
| 解体・造成工事 | `lp/kaitai/` | Livii |
| 太陽光・蓄電池 | `lp/solar/` | Livii |
| 家具の新調 | `lp/kagu/` | Livii |
| 住まいのお困りごと | `lp/komarigoto/` | Livii |
| 不動産の売買 | `lp/baibai/` | Livii不動産 |
| 賃貸の仲介 | `lp/chintai/` | Livii不動産 |
| 収益物件の管理 | `lp/kanri/` | Livii不動産 |

- LP の HTML は `lp/_build.py` から書き出している。文章を直すときは `_build.py` の `LPS` を直し、HP フォルダで `python3 lp/_build.py` を実行する。HTML を直接直さない。
- 構成はどの LP も同じ：最初の画面（見出し・電話/LINE）→ お悩み → 選ばれる理由 → 対応内容 →（売買・賃貸は物件一覧）→ 経営理念（Mission・Value）→ 流れ →（あればお客様の声）→ 代表 → よくある質問 → お問い合わせ。
- 経営理念の文言は総合トップ（`index.html` の `#philosophy`）と `_build.py` の `MISSION` / `VALUE` の2か所にある。変えるときは両方直す。
- 写真は `assets/img/photos/` の仮写真（Unsplash License）。実際の写真に差し替えるときは同じファイル名で置き換えるか、`_build.py` の `photo` を変える。

## 口コミ（Livii のお客様の声）

`reform/index.html` の「お客様の声」は、`assets/data/reviews.js` の口コミを横スライドで全件表示する。件数と平均の星も自動で計算される。

### 口コミが届いたとき（スクリーンショットや文章で受け取る）

1. 口コミの文面を、原文のまま一字一句写す（言い回しを直さない・要約しない）。読み取れない文字があれば確認する。
2. `reviews` の先頭に `{ name, rating, tag, text }` を追加する（新しい口コミが最初に表示される）。
   - `name`: Google に表示されている名前（表示は「○○ 様」になる）
   - `rating`: 星の数（1〜5）
   - `tag`: 工事の種類（外構工事、外壁・塗装、店舗づくり など。分からなければ省く）
3. 同じ口コミが二重に入っていないか確認する。
4. 投稿日（「1か月前」など）は時間がたつとずれるので入れない。
5. 星の評価だけで本文がない口コミは `text: ""` で入れる。カードには出ず、件数と平均の星にだけ含まれる。

### Google との自動連動（未設定）

- Places API（一般向け）は最新5件までしか取れないため、全件表示には使えない。
- 全件を自動で取るには、Google ビジネスプロフィール API（オーナー向け・利用申請が必要）か、口コミ連携サービス（Trustindex・Elfsight など）を使う。
- どちらの場合も、取得した口コミで `assets/data/reviews.js` を書き換える形にすれば、ページ側は変えなくてよい。
- `mapsUrl` に Google マップの Livii のページの URL を入れると、「Googleマップで口コミを見る・書く」ボタンが表示される。
