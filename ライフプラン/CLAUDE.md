# ライフプラン

お客様の家計の将来（キャッシュフロー）と、万一のときに必要な保障額を計算するソフトです。保険の営業担当が使う「ライフプランソフト」と同じ役割で、住宅購入の相談（Livii不動産）や、保険・家計の見直し相談で使います。

`index.html` をブラウザで開けば、そのまま使えます（インターネット接続・インストール不要）。

## できること

| 画面 | 内容 |
| --- | --- |
| ① 家族・収入 | 本人・配偶者・お子さま、手取り年収、退職、年金、児童手当、今の貯蓄 |
| ② 支出 | 生活費、住まい（賃貸・持家・購入予定と住宅ローン）、保険料、車 |
| ③ ライフイベント | 旅行・リフォーム・相続・介護など。収入はプラス、支出はマイナス。毎年くり返しもできる |
| キャッシュフロー | 本人が95歳（変更可）になるまでの毎年の収入・支出・貯蓄残高。グラフと表 |
| 必要保障額 | 本人に万一があった場合の、ご家族に必要なお金・遺族年金など用意できるお金・不足額 |

- お客様ごとにプランを作れる（「＋ 新規」「複製」で、たとえば「購入しない案」「4,000万円の物件案」を並べて比べる）。
- 「印刷・PDF」でキャッシュフローと必要保障額を印刷する。ブラウザの印刷画面で「PDFに保存」を選べば、お客様にお渡しする資料になる。

## 対応方針

- 金額の単位はすべて **万円**。収入は手取り（税・社会保険料を引いた後）で入れる。
- 入力したデータは、使っているパソコン・スマホのブラウザの中にだけ保存される。サーバーには送らない。
  - 別の端末で使う・保管するときは「書き出し」で `.json` ファイルにして、「読み込み」で戻す。
  - お客様の `.json` ファイルは個人情報なので、このリポジトリには入れない（コミットしない）。
- 計算結果は目安。お客様には「将来を約束するものではない」「年金額はねんきん定期便で確認」と必ず伝える。
- 保険商品の勧誘に使う場合は、保険募集の資格とルールに従う。必要保障額は「不足があるかどうか」の目安として示し、特定の商品を断定的にすすめない。

## 計算のしかた（概要）

- 給与は退職年齢まで昇給率で増える。退職した年に退職金、その後は「退職後の収入」を「働く年齢まで」受け取る。年金は受け取り開始年齢から。
- 生活費・その他の支出・車の費用には物価上昇率をかける。本人の退職後は「退職後の生活費」に切り替わる。
- 住宅購入は、購入年に頭金＋諸費用を払い、翌月から元利均等で返済。購入年から家賃がなくなり、固定資産税・修繕費がかかる。
- 教育費は公立・私立と大学の種類ごとの年額の目安（`app.js` 先頭の `EDU` / `UNIV`）。
- 貯蓄は前年末の残高に運用利回りをかけてから、その年の収支を足す（残高がマイナスのときは利回りなし）。
- 必要保障額 ＝ 遺族に必要なお金（生活費・住居費・教育費・お葬式）− 用意できるお金（配偶者の収入と年金、遺族基礎年金、遺族厚生年金、中高齢寡婦加算、貯蓄、死亡退職金）。そこから加入中の死亡保険金を引いた残りが「不足している保障」。
  - 遺族厚生年金は、本人の手取り年収から額面を推計し、加入25年（300月）とみなした最低保障の額で概算する。わかっていれば実額を入れる。
  - 物価上昇は入れない。住宅ローンは団信で完済とするのが初期設定。

## 数字の更新

制度や統計が変わったら `app.js` の先頭「目安の数字」を直す。

| 定数 | 中身 | 見直す時期 |
| --- | --- | --- |
| `EDU` | 幼稚園〜高校の学習費（年額） | 文部科学省「子供の学習費調査」の公表時（2年ごと） |
| `UNIV` / `AWAY_YEARLY` | 大学などの学費・入学金・自宅外の仕送り | 数年に1回 |
| `IZOKU_KISO` / `IZOKU_KID12` / `IZOKU_KID3` / `CHUKOREI` | 遺族基礎年金・子の加算・中高齢寡婦加算（年額） | 毎年4月（年金額の改定） |
| 児童手当（`simulate` の中） | 0〜2歳 月1.5万円、3〜18歳 月1万円、第3子以降 月3万円 | 制度改正時 |
