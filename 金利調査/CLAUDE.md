# 金利調査

お客様への提案（住宅購入・リフォーム・車の購入）に使うため、銀行のローン金利を **毎月1日** に調べて表にする部署です。

## 対象

### ローンの種類（3つ）
1. **住宅ローン** … 変動金利と10年固定。どちらも「適用金利の下限（最優遇）」を載せる。
2. **リフォームローン** … 無担保のリフォーム専用ローン。専用商品がなければ、その旨と代わりの商品（多目的ローンなど）を書く。
3. **カーローン** … マイカーローン・オートローン・カーライフローン。

## 対応方針

### 1. 作るファイル
- `金利調査/YYYY-MM.md`（例: `2026-12.md`）を毎月1つ作る。`テンプレート.md` をコピーして使う。
- 1日が土日祝で公式サイトの更新が遅れる場合は、翌営業日の値でもよい。その場合は確認日を書く。

### 2. 調べ方
1. 各金融機関の**公式サイト**を最優先にする。
2. 公式サイトが読めないときは、Web検索で公式ページの掲載内容を確認する。それも無理ならイー・ローンなどの比較サイトを使い、**出典欄に比較サイト名を書く**。
3. ボット対策で拒否されたサイトを、ヘッダー偽装などで回避しようとしない。
4. 数字が見つからないときは推測せず **「未確認」** と書く。前月以前の数字を使うときは「（10月時点）」のように時点を書く。

### 3. 表の書き方
- 金利は `年1.375%〜` のように、下限を `〜` 付きで書く。幅があるものは `2.45%〜3.05%`。
- 変動／固定、保証料込／別、Web申込限定などの条件は、セルの中に短く書くか表の下の注に書く。
- 各金融機関の出典URLと、ページに書かれた適用日（例: 2026-11-01〜11-30）を「出典」表に書く。
- 前月との比較欄を付ける（上がった ↑、下がった ↓、同じ →、前月が未確認なら空欄）。

### 4. まとめ
- 表の下に「今月のポイント」を3行以内で書く（一番低い金利、大きく動いた銀行など）。
- 熊本地震罹災者向けの特別金利など、対象が限られる金利は表に入れず注に書く。

### 5. 毎月の自動実行
- 毎月1日にクラウドのスケジュールタスク「月次ローン金利調査」が新しいセッションを起動し、この手順で `YYYY-MM.md` を作ってコミット・プッシュする。
- 実行環境は「livii」（銀行サイトへの接続を許可済み）。新しい金融機関を追加したときは、その環境の許可ドメインにも追加する。

## 注意
- 表の金利は提案の目安。お客様に示すときは「実際の金利は審査と借入時点で決まる」ことを必ず添える。
