# 住宅プラン

家の間取り（平面図）・外構図を描いて、3Dの外観パース・内観（ウォークスルー）で見られるソフトです。新築・建て替え・リフォームの打ち合わせで、お客様にイメージを見せるときに使います。

`index.html` をブラウザで開けば、そのまま使えます（インターネット接続・インストール不要）。3D表示には `lib/three.min.js`（three.js r147、MITライセンス。`lib/three-LICENSE.txt`）、PDFの読み込みには `lib/pdf.min.js`（pdf.js 3.11、Apache-2.0。`lib/pdfjs-LICENSE.txt`）、OCR には Tesseract（Apache-2.0。`lib/tesseract-LICENSE.txt`）と日本語データを同梱しています。

## できること

| 画面 | 内容 |
| --- | --- |
| 間取り（平面図） | 部屋をドラッグで描く（910mmのマス目に合わせる）。壁は部屋から自動でできる。ドア・引戸・玄関ドア・窓（腰窓・掃出し窓・小窓・高窓）を壁に付ける。家具・設備を置く（5分類・54種類）。部屋ごとに床材・壁紙・アクセントクロス・天井を選ぶ。1階〜4階。部屋ごとの帖数・各階の床面積・延床面積（㎡・坪）を表示 |
| 外構図 | 敷地・道路・建物の配置。外構を置く（5分類・50種類）。舗装は仕上げ（土間コン・洗い出し・タイル・インターロッキング・乱形石・レンガ・芝・人工芝・デッキ材など）を選べる。建ぺい率・容積率の目安を表示 |
| 3D外観パース | 建物と外構を3Dで見る。空・雲・映り込みつき。視点（南東・南西・北東・北西・正面・真上・人の目線）、「夜景」で外構照明・カーポート・玄関・窓の明かり、季節（夏至・春分秋分・冬至）と時刻で日当たりと影を確認。「◯階まで」で上の階と屋根を外して中を見られる。画像（PNG）で保存 |
| 3D内観 | 部屋の中を歩いて見る（目の高さ1.5m）。階・部屋を選んで移動。画像で保存 |
| 物件・設定 | プラン名・お客様名、敷地の大きさ・道路の向きと幅員、基礎・階高・天井高、屋根の形（切妻・寄棟・片流れ・陸屋根）・勾配・軒の出。外壁材・屋根材（見本つき）、階ごとの外壁（ツートン）、サッシ・玄関ドア・室内ドア・軒天の色、家全体の標準の壁紙・天井。外観のおすすめ組み合わせ8種類 |

- プランごとに作れる（「＋ 新規」でサンプルから・白紙から。「複製」で「A案」「B案」を並べて比べる）。
- 「図面を印刷・PDF」で、1枚目にプレゼンボード（配置図に採用商品の番号・人の目線パース・夜景・鳥瞰・仕様一覧）、続けて各階の平面図・外構図・外観パース・1階の中の鳥瞰を A4 横で印刷する。ブラウザの印刷画面で「PDFに保存」を選べば、お客様にお渡しする資料になる。

| 外壁（金属） | アイジー工業（ガルスパン） |
| 屋根 | ケイミュー（カラーベスト コロニアルクァッド・グラッサ、ROOGA）、ニチハ（横暖ルーフ）、アイジー工業（スーパーガルテクト）、鶴弥（スーパートライ110） |
| 壁紙 | サンゲツ（SP・ファイン・リザーブ）、リリカラ（ライト・V-wall・LV） |
| 床 | 大建工業（トリニティ・hapia フロア・健やかおもて）、永大産業（スキスムS）、パナソニック（ベリティス）、サンゲツ・東リ（CF）、LIXIL（床タイル） |
| サッシ・ドア | YKK AP（APW330・ヴェナートD30）、LIXIL（サーモスX・ジエスタ2）、大建工業・パナソニック（室内ドア） |

- 外構・家具を選ぶと「商品（メーカー）」と色を選べる。選んだ商品は外構図に番号で出て、プレゼンボードの仕様一覧に載る。
- サッシ・玄関ドア・室内ドアは「物件・設定」で選ぶ。
- **実物の柄を使いたいとき**は「物件・設定」→「メーカーのテクスチャ画像を取り込む」で、各社が配っている CAD・テクスチャデータや実物の写真を、実寸（mm）を入れて材料にする。画像はプランの中に保存される（512px に縮小）。カタログの写真を使うときはメーカーの利用条件を確認する。
- メーカーのロゴ・カタログ写真そのものはソフトに入れない。

## 測量図・敷地図の読み込み（`survey.js`）

外構図の左の「PDF・画像を読み込む」から読み込む。PDF は pdf.js（`lib/pdf.min.js`・`lib/pdf.worker.min.js`、Apache-2.0）で1ページ目を画像にする。

- **文字の入った PDF（CAD から出したもの）**：座標求積表（点名・X・Y）・地積・縮尺（1/250 など）を自動で読み取る。右に座標と、座標から計算した面積・図面の地積の差が出る。「この座標で敷地を作る」で敷地がその形になる（測量の X＝北、Y＝東）。
- **スキャンした PDF・写真**：文字が読めないので「下図」として表示する。
  1. 図面の縮尺を選ぶ（用紙どおりの大きさの PDF のとき）か、「2点で縮尺合わせ」で長さがわかっている2点をクリックして実際の長さ（mm）を入れる
  2. 「下図を動かす」・回転（↺90°・↻90°）で向きと位置を合わせる
  3. 「敷地境界をなぞる」で角を順にクリック（最初の点かダブルクリックで閉じる）
- **OCR（文字認識）**：スキャン・写真の図面は「OCR：ページ全体を読む」で地積・縮尺・座標を探す。座標の表は「範囲を選んでOCR」で表だけを囲むと正確に読める。
  - Tesseract（`lib/tesseract-core-lstm.wasm.js`）と日本語データ（`lib/ocr-jpn-data.js`、tessdata_best_int）を使うときだけ読み込む。ネット不要で、図面はどこにも送らない。初回の準備は数秒、ページ全体は10〜30秒かかる。
  - 読み取った文字は右の欄で直せる。座標を「K1 -12345.120 5432.100」の形で打ち込んで「この文字から読み直す」でも敷地を作れる（OCR を使わない手入力）。
  - マイナスの抜けは、同じ列のほかの値に合わせて自動で直し「符号を補正」と出す。座標から計算した面積が図面の地積と2%以上ちがうと警告が出るので、測量図と見比べる。
  - 手書き・かすれ・斜めの撮影は読み間違いが増える。OCR の結果は必ず測量図の数字で確認する。
- 敷地の角（赤い□）は、選択ツールでドラッグして直せる。辺の長さ（m）が図に出る。
- 読み取った数字・なぞった形は目安。正式な面積・境界は測量図の数字で確認する。
- 下図は縮小してプランの中に保存する（測量図はお客様の情報なので、書き出した .json はリポジトリに入れない）。

## 車（トヨタ車）

外構の「車（トヨタ車）」を置いて、右のパネルで車種を選ぶと、カタログの目安の寸法（全長×全幅×全高）になる。軽自動車（ピクシス エポック）、軽バン・軽トラック（ピクシス バン・トラック）、コンパクト（ヤリス・アクア・ルーミー）、ミニバン（シエンタ・ノア・ヴォクシー・アルファード）、セダン（カローラ・プリウス・クラウン）、SUV（ライズ・ヤリス クロス・カローラ クロス・RAV4・ハリアー・ランドクルーザー）、スポーツ（GR86・GRスープラ・GRヤリス）、商用（プロボックス・ハイエース）。3Dの形は車の種類ごとの簡単なシルエット。寸法は年式・グレードで変わるので、駐車スペースの検討は最新のカタログ値で確認する。

## 使い方のコツ

- 部屋は四角で描く。L字の部屋は、四角を2つ並べて**同じ名前**にすると間の壁が消えて1部屋になる（帖数も合計される）。
- 部屋の外まわりは外壁（厚さ150mm）、部屋どうしの境目は間仕切り壁（105mm）が自動でできる。部屋の中に別の壁が欲しいときは「壁」で描く。
- 「バルコニー」「ポーチ」「テラス」という名前の部屋は外の床として扱う（床面積に入れない・屋根をかけない。2階以上のバルコニーには手すり壁が付く）。
- 2階以上の「階段」の部屋は床を抜く（下の階の階段が見える）。階段は家具の「階段（直階段）」を置く。太い線の側が上り切る側。
- 屋根は一番上の階の部屋に自動でかかる。上の階がない1階部分には、上の階の壁側を高くした片流れの下屋が自動でかかる。
- 家具は太い線の側が背中（壁につける側）。R キーまたは「90°回す」で向きを変える。点線の家具（ペンダントライト・エアコン）は天井・壁の高い位置に付く。
- アクセントクロスは、部屋を選んで「北・南・東・西の壁」と壁紙を選ぶ。図面では、その壁に色の線が出る。
- 操作：Delete で削除、Ctrl+Z で元に戻す、Ctrl+D で複製、Esc で選択に戻る。何もない所のドラッグ・右ドラッグで画面移動、ホイール（スマホはピンチ）で拡大縮小。

## 対応方針

- 長さの単位はすべて **mm**。尺モジュール（1マス＝910mm）を基本にする。
- 図面の向きは上が北。道路の向きは「物件・設定」で合わせる。日影は北緯33°（熊本）で計算している。
- 入力したデータは、使っているパソコン・スマホのブラウザの中にだけ保存される。サーバーには送らない。
  - 別の端末で使う・保管するときは「書き出し」で `.json` ファイルにして、「読み込み」で戻す。
  - お客様名の入った `.json` ファイル・画像・PDF は、このリポジトリには入れない（コミットしない）。
- このソフトの図面は**打ち合わせ用の参考図**。寸法・面積は壁の中心線で計算した目安で、構造・法規（斜線制限・採光・確認申請など）のチェックはしていない。お客様には「参考図であり、実際の設計図・施工図ではない」と必ず伝える。印刷物にも同じ注意書きが入る。
- 建ぺい率・容積率は目安。用途地域の上限との比較や正式な面積は、設計者・役所で確認する。
- メーカーの商品名・型番・ロゴは図面や画像に入れない（色・形は一般的なもので表す）。

## 直すときのメモ

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の部品 |
| `style.css` | 見た目（他のソフトと同じ色づかい） |
| `survey.js` | 測量図・敷地図の読み込み（PDF→下図、座標・地積・縮尺の読み取り）、不整形の敷地 |
| `products.js` | メーカー商品（仕上げ材のメーカー品・外構や住設の `PRODUCTS`・サッシやドアの `SET_PRODUCTS`）と追加の模様 |
| `materials.js` | 仕上げ材のカタログ（`EXT_WALLS` `ROOF_MATS` `WALLPAPERS` `FLOOR_MATS` `PAVINGS`）と模様の描き方（`PATS`）。材料を足すときはカタログに1行足す。新しい模様は `PATS` に足す |
| `app.js` | データ・2D図面の描画と編集・設定・印刷。家具・外構・建具の種類と初期サイズは先頭の `OPENINGS` `FURN` `EXT` に足す（`cat` は一覧の見出し） |
| `view3d.js` | 3D表示。家具・外構の3Dの形は `itemMesh()` の `switch` に足す。屋根は `roofGroup()` |

- データは `localStorage` の `livii-house-plan-v1` に保存している。形を変えるときは、古いデータを読み込めるようにする（足りない項目は `ensurePlan()` で初期値を補う）。
