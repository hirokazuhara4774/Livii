# 収益物件

アパート・マンション・区分マンションなどの収益物件（投資用不動産）を買ったときの、利回り・毎年の手取り・税金・売却したときの損益を計算するソフトです。Livii不動産で投資用物件を紹介・相談するときに使います。

`index.html` をブラウザで開けば、そのまま使えます（インターネット接続・インストール不要）。

## できること

| 画面 | 内容 |
| --- | --- |
| ① 物件・融資 | 物件価格・建物の価格・構造・築年数・諸費用、自己資金・金利・返済期間・返済方法。途中で金利が上がる場合も見られる |
| ② 収入・経費 | 満室家賃・空室率・家賃の下落率、管理費・固定資産税・保険・修繕・大規模修繕 |
| ③ 税金・売却 | 個人か法人か・税率・損益通算、売却する年・売却時の利回り・売却費用 |
| 収支シミュレーション | 表面・実質利回り、1年目の収支、返済比率・DSCR・損益分岐の入居率・デッドクロスなどの目安、毎年の収支表とグラフ |
| 売却・投資判断 | 売却したときの手取り・最終的な損益・IRR。何年目に売るといくら残るかの一覧 |

- 物件ごとに作れる（「＋ 新規」「複製」で、たとえば「自己資金1,000万円案」「金利3%案」を並べて比べる）。
- 「印刷・PDF」で結果を印刷する。ブラウザの印刷画面で「PDFに保存」を選べば、お客様にお渡しする資料になる。

## 対応方針

- 金額の単位はすべて **万円**。家賃は月額、経費は年額で入れる。
- 入力したデータは、使っているパソコン・スマホのブラウザの中にだけ保存される。サーバーには送らない。
  - 別の端末で使う・保管するときは「書き出し」で `.json` ファイルにして、「読み込み」で戻す。
  - お客様名の入った `.json` ファイルや、販売前の物件情報はこのリポジトリには入れない（コミットしない）。
- 計算結果は目安。お客様には「家賃・空室・金利・売却価格を約束するものではない」「税金は概算なので税理士に確認」と必ず伝える。
- 空室率・家賃下落率・売却時の利回りは、甘く見ない（空室5〜15%、下落0.5〜1%/年、売却利回りは今の利回り＋0.5〜1%）。楽観的な数字だけの資料は作らない。
- 「必ず儲かる」「家賃保証だから安心」など断定的な説明はしない（宅地建物取引業法の断定的判断の提供の禁止）。
- 融資の金利・期間は、実際の金融機関の条件で入れる。参考に `金利調査/` の最新の表を見る。

## 計算のしかた（概要）

- 購入は1年目の初めとし、1年目から満室家賃 ×（1−空室率）の家賃が入る。家賃は毎年、下落率の分だけ下がる。
- 経費 ＝ 管理委託費（実際の家賃収入の%）＋ 固定費（建物管理・固定資産税・保険・その他、経費の上昇率で毎年上がる）＋ 修繕・原状回復（満室家賃の%）＋ 大規模修繕（指定した年）。
- 営業収益（NOI）＝ 実際の家賃収入 − 経費。税引前の手取り ＝ NOI − ローン返済（元金＋利息）。
- ローンは毎月の返済を積み上げて計算する。金利が変わる年は、その時の残高と残りの回数で返済額を計算し直す。
- 減価償却：諸費用も含めた購入総額を、建物と土地の価格の割合で分け、建物分を耐用年数で割る（定額法）。中古の耐用年数は簡便法（法定耐用年数を過ぎていれば 法定×20%、途中なら（法定−築年数）＋築年数×20%、端数切り捨て・最低2年）。設備の分け方や初年度の月割りはしない。
- 税金 ＝（実際の家賃収入 − 経費 − 借入利息 − 減価償却）× 税率。
  - 個人：赤字は「損益通算する」にチェックがあれば、その分の税金が減る（土地分の借入利息は通算できない等の細かい決まりは入れていない）。
  - 法人：赤字は10年間くり越して、その後の黒字・売却益と相殺する。
  - 大規模修繕はその年の経費としている（実際は資本的支出として減価償却になる場合がある）。
- 売却価格 ＝ 売却した翌年の満室家賃（年額）÷ 売却時の利回り。
- 売却の手取り ＝ 売却価格 − 売却費用 − ローン残高 − 税金。税金は（売却価格 − 売却費用 − 帳簿価額）× 税率。帳簿価額 ＝ 購入総額 − 減価償却の累計。
  - 個人は6年目の末以降の売却を長期（20.315%）、それより前を短期（39.63%）とする（売った年の1月1日時点で5年超かどうかを安全側に判定）。法人は法人の税率。
- 最終的な損益 ＝ それまでの手取りの合計 ＋ 売却の手取り − 自己資金。IRR は自己資金を元手にした年あたりの利回り（税引後）。

## 判断の目安（画面に表示するもの）

| 指標 | 目安 |
| --- | --- |
| 返済比率（返済 ÷ 満室家賃） | 50%以下 |
| DSCR（NOI ÷ 返済） | 1.2倍以上 |
| 損益分岐の入居率 | 80%以下 |
| イールドギャップ（実質利回り − 金利） | 1.5%以上 |
| デッドクロス | 元金返済が「利息＋減価償却」を上回る年。帳簿は黒字でも手取りが減り始める |

## 数字の更新

税制が変わったら `app.js` の先頭「目安の数字」を直す。

| 定数 | 中身 | 見直す時期 |
| --- | --- | --- |
| `LIFE` | 建物の構造ごとの法定耐用年数（住宅用） | 税制改正時 |
| `CAP_TAX_LONG` / `CAP_TAX_SHORT` | 譲渡所得の税率（長期・短期、復興特別所得税込み） | 税制改正時（復興特別所得税は2037年まで） |
| `LONG_FROM` | 何年目の末から長期譲渡とみなすか | 変えない |
| `CORP_CARRY` | 法人の欠損金くり越し年数 | 税制改正時 |
